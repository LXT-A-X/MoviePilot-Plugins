# 字幕字体代理（FontInAssProxy）使用手册 — MoviePilot V3 版

反代 Emby/Jellyfin 字幕流，把字幕用到的字体实时**子集化**并以内嵌字体（`[Fonts]` 段）
写回 ASS，让任何设备（电视、播放器、没装字体的环境）都能正确显示特效字幕，不再出现
乱码 / 方块字 / 缺字。

## 功能特性

- **实时子集化注入**：播放时抓取字幕 → 解析用到的字体 → 只把需要的字形内嵌进字幕，
  一句话：不用再把字体装到播放设备上。
- **uharfbuzz 引擎**：子集化走 HarfBuzz C 实现（比纯 Python fontTools 快约 140 倍），
  失败自动回退 fontTools，兼容性有保障；复杂文字（阿拉伯文、缅甸文等）布局闭包完整保留。
- **内置反代端口**：默认 `8097` —— 客户端直接把 Emby 地址指到反代端口即可使用，无需外部反代。
- **1.7 万字体大库支撑**：SQLite 索引 + watchdog 增量监听，新增字体自动收录，无需手动重建。
- **精准匹配**：内部名 > 文件名分层匹配，容器格式优先（ttf > ttc > otf > otc），
  中文名/拼音名/日文名多编码识别（GBK/BIG5/UTF-16）。
- **双层缓存**：内存 LRU + 磁盘缓存，重复播放零等待；磁盘缓存默认保留 1 天、每 4 小时清理。
- **已有子集自动跳过**：原字幕已内嵌 `[Fonts]` 时直接透传，不给已子集化的字幕二次加工。

## 安装

1. MoviePilot V3 插件市场添加仓库：`https://github.com/LXT-A-X/MoviePilot-Plugins`
2. 搜索「字幕字体代理」并安装（V3 版为 3.0.0）
3. 启用插件

> 首次启用会自动 `pip install` 依赖（fonttools / watchdog / cachetools / httpx /
> charset-normalizer / uharfbuzz）。若宿主禁用安装，请手动在容器内执行
> `pip install -r requirements.txt`。

## 快速上手（推荐：内置反代）

1. 打开插件「设置」页
2. **Emby/Jellyfin 地址**：填 `http://<emby-ip>:8096`（MoviePilot 容器需能访问）
3. **字体目录**：填字体库路径，多个用 `;` 分隔（需挂载进容器）
4. **启用内置反代端口**：打开，默认 `8097`
5. 保存 → 状态页看「字体索引」是否就绪（1.7 万字体约数秒）
6. MoviePilot 容器把 `8097` 端口映射出来（`-p 8097:8097`）
7. 客户端（Kodi / Jellyfin App / 电视）里把 Emby 服务器地址填成
   `http://<moviepilot-ip>:8097` —— 播放时字幕自动走代理并嵌入字体


## 设置项说明

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 关闭时字幕请求原样透传 |
| Emby/Jellyfin 地址 | 回源地址，需容器可访问 |
| 回源 API Key | 留空则转发客户端原始 `api_key`；填了则覆盖（客户端 key 无字幕权限时用） |
| 字体目录 | 字体库路径，`;` 分隔，递归扫描监听 |
| SRT 兜底字体 | SRT 或无明确字体名时的兜底字体 |
| SRT 转 ASS 字号 | SRT 转 ASS 的默认字号 |
| 处理结果缓存 | 内存 + 磁盘双层，默认开 |
| 缓存有效期（小时） | 磁盘缓存保留时长，默认 24（1 天），每 4 小时清理 |
| 子集化并发上限 | 保护 MP 主进程，超限请求降级透传 |
| 处理失败时返回原始字幕 | 失败透传原字幕（关则 500） |
| 内置反代端口 | 默认 8097，客户端直连本端口 |
| 启用通知 | 缺字体 / 处理错误时发消息通知 |

## 状态页说明

- **字体索引**：`就绪 · fontTools x.y.z · uharfbuzz x.y` —— uharfbuzz 未装会提示兜底
- **反代端口**：显示内置反代是否运行
- **字幕缓存**：内存条数 + 磁盘文件数
- **缺失字体**：历史上没匹配到的字体名及次数，可一键清除
- **插件日志**：每次处理按 FontInAss 风格记录（字幕URL / 加载字体耗时 / 子集化字符数 /
  ass分析 / 子集化嵌入 / 完成体积变化），播放后可在此回溯排查

## 常见问题

**Q：状态页显示 uharfbuzz 未安装？**
容器内执行 `pip install "uharfbuzz>=0.40.0"` 后重启插件。

**Q：某字体一直提示缺失，但库里明明有？**
先到「状态页 → 重建字体索引」触发一次全量重建（V3 升级后首次启动会自动重建）。
若仍缺失，把「插件日志」里该字体名称发作者排查（可能是编码/名字特殊，如 GBK 繁体名）。

**Q：播放后日志显示「字幕已含 [Fonts] 内嵌字体，跳过处理」？**
正常 —— 该字幕已经内嵌过字体，插件直接透传，不做二次加工。

**Q：内置反代连不上？**
确认 8097 已映射、插件「内置反代端口」开关已开、状态页「反代端口」显示运行中。
