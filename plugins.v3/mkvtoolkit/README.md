# MKV 工具箱（MkvToolkit）

> 在 MoviePilot 里对 `.mkv` 做「容器层手术」：内封外挂字幕、增删与排序音轨、改语言 / 轨道名 / 默认 / 强制标记、写字体附件、改章节与标题——**全程不转码、不重编码视频、不剪片**。

| 项目 | 内容 |
| --- | --- |
| 插件名称 | MKV 工具箱（MkvToolkit） |
| 版本 | **0.1.51**（本手册按该版本代码核对） |
| 作者 | LXT-A-X |
| 适用版本 | **MoviePilot V3**（`system_version` 要求 `>= 3.2.0`）；仅收录于 `plugins.v3/`，**没有 V2 版本** |
| 权限等级 | 2（管理员插件，设置与页面入口仅管理员可见） |
| 页面渲染 | Vue 联邦页面（后端声明 `vue` + `dist/assets`），自带顶部栏、编辑 / 队列 / 历史 / 设置四个区域 |
| 外部依赖 | MKVToolNix（`mkvmerge` / `mkvpropedit` / `mkvextract`）、`ffmpeg` / `ffprobe`；可选 `7z` / `unrar`（仅用于解压字体压缩包） |
| 插件数据目录 | MoviePilot 的插件数据目录（`/config/plugins/MkvToolkit`），仅存放队列、历史、上传素材、输出与备份 |
| 插件日志 | `<LOG_PATH>/plugins/mkvtoolkit.log`（容器默认 `/config/logs/plugins/mkvtoolkit.log`） |

## 一、它到底解决什么问题

下载回来的 MKV，往往「视频没问题，但周边一团乱」：

- 字幕是一堆外挂的 `.srt / .ass`，放在剧集目录里，Emby / Jellyfin 能读、电视盒子读不到，换台设备就丢字幕；
- 国语 / 粤语 / 评论音轨想要但放不进去，或者轨道顺序乱、默认轨错，播放器一开就是外语；
- 语言标签全是 `und`（未指定），播放器不知道哪条是中文；
- 特效字幕用的字体在别人的电脑上装了，自己这边缺字体 → 满屏方块 / 花字错位；
- 片头章节乱七八糟或者干脆没有，容器标题写着 `xxx.mkv` 这种无意义字符串。

这些需求**都不需要重新压一遍视频**（重编码要几小时、还会掉画质）。它们只是「容器里的几条轨道、几个属性、几个附件」的重新排列，MKVToolNix 几秒钟就能做完——但命令行参数又多又难记，手机上更没法操作。

**MKV 工具箱就是把这件事做成网页操作**：选文件 → 勾勾点点 → 看一遍「将要执行的命令和差异」→ 确认入队 → 后台跑完。视频流原样 copy，画质零损失，速度取决于硬盘 IO。

### 1.1 三种底层手段（决定了「快」和「稳」）

插件不会硬套一种工具，而是按「你要改什么」自动选最小代价的路径：

| 引擎 | 什么时候用 | 代价 | 说明 |
| --- | --- | --- | --- |
| `mkvpropedit` | 只改属性：语言、轨道名、默认 / 强制标记、标题、章节、附件增删 | 先复制一份文件再改属性，秒级~分钟级（看文件大小） | 不重新封装，轨道数据一个字节不动 |
| `mkvmerge` | 结构变动：加字幕 / 加音轨 / 删轨道 / 重排顺序 / 改附件集 / 源文件不是 MKV 需重封装 | 完整重写一遍输出文件（copy 编码） | 最通用的路径，轨道用 `copy` 方式写入 |
| `ffmpeg` | **降级**：容器里没有 MKVToolNix，但用户主动开启「降级执行」 | 完整重写 | 能力减配：附件、tags、轨道 UID 等细节可能丢失，默认关闭 |

### 1.2 它明确「不做」什么

- ❌ 不转码、不压缩、不改分辨率码率；
- ❌ 不剪片、不合并、不切分（不提供 trim / split）；
- ❌ 不下载字幕、不刮削、不整理媒体库、不改文件名；
- ❌ 不发通知、不接 Telegram 命令、不监听下载器事件（全部操作都由你在页面上发起）；
- ❌ 不修改视频画面／音频编码本身，只动「容器里的轨道与元数据」。

### 1.3 为什么所有写操作都要先「预览」

插件把「编辑」和「执行」严格分开：

1. 你在页面上的所有勾选只维护一份**期望状态**（想保留哪些轨、加哪些素材、改成什么语言）；
2. 点「预览并确认」→ 后端 `/plan` 做一次 **dry-run**，把差异、警告、阻塞项、最终命令行全部算出来，**此时一个字节都不写**；
3. 确认后才入队，由后台 worker 真正执行，执行时先写临时文件，校验通过才落盘。

这样设计的好处：参数填错、素材选错、输出路径冲突、磁盘不够，都在「还没动文件」的时候被拦下来。

## 二、核心功能（按模块）

### 2.1 引擎探测与安装

- 打开插件页 / 设置页都会自动探测 5 个工具：`mkvmerge`、`mkvpropedit`、`mkvextract`、`ffmpeg`、`ffprobe`；
- **查找顺序**（逐个候选执行 `--version` 自检，自检不过就跳过）：
  1. 你在设置里手填的绝对路径；
  2. 插件数据目录下的 `bin/`；
  3. 容器 `PATH`（`which`）；
  4. `/usr/bin`、`/usr/local/bin`。
- **执行模式判定**：
  - `mkvmerge` + `mkvpropedit` 都在 → 模式 `mkvmerge`（完整能力）；
  - 否则 `ffmpeg` + `ffprobe` 都在 → 模式 `ffmpeg`（降级，需在设置里开启「降级执行」才真跑）；
  - 都不满足 → `none`（只能查看 / 预览，不能执行）。
- 顶部栏用三个小圆点状态条显示 `mkvmerge`、`ffmpeg`、压缩包工具是否就绪，鼠标悬停可看版本与缺失原因。
- **三种安装方式**（互斥，同一时间只允许一个安装任务在跑）：
  - **apt 安装**：要求容器内是 root（`apt-get update` + `apt-get install -y --no-install-recommends`）。MKVToolNix 一个 `mkvtoolnix` 包含三个工具；`ffmpeg` 包含 ffmpeg/ffprobe；7z 会依次尝试 `p7zip-full`、`7zip`、`7zip-full`；unrar 会依次尝试 `unrar-free`、`unrar`。
  - **AppImage 解包**（免 root）：下载官方 `MKVToolNix_GUI-103.0-x86_64.AppImage` 到插件数据目录 `appimage/`，执行 `--appimage-extract`，再在 `bin/` 生成三个带 `LD_LIBRARY_PATH` 的启动脚本。**只支持安装 MKVToolNix 三个工具**，选其它目标会直接提示「只能用 apt 安装」。
  - **手动指定路径**：填 `mkvmerge` 的绝对路径 → 自检 `--version` → 把它同目录下的 `mkvpropedit` / `mkvextract` 软链到 `bin/`（软链失败则退回直接使用原路径）。
- 安装进度、实时日志在设置页弹窗里滚动显示（后台线程执行，关掉弹窗也会继续，完成后自动刷新引擎状态）。

### 2.2 媒体目录浏览（文件树）

- 只列出**配置的媒体根目录内**的目录与 `.mkv`（`.m2ts` 也能列出，用于重封装）；
- 目录**懒加载**（点开才请求子目录），隐藏以 `.` 开头的文件 / 目录；
- 顶部有搜索框（在当前已展开的树里按名称过滤），每个根目录一个可点击的根标签；
- 文件行会显示该文件当前的**任务状态徽标**（待开始 / 运行中 / 已完成 / 失败 / 已取消），从 `/file-statuses` 拉取，按路径去重取最新一条；
- 桌面端文件树常驻左侧；窄屏（手机 / 宿主弹窗很窄时）收进「文件」按钮弹出的抽屉里。

### 2.3 打开文件后的探测

选中文件后，后端 `/probe` 会做这些事：

1. **容器与轨道**：优先 `mkvmerge -J`（拿到最全的轨道属性、语言 IETF 标签、像素尺寸、附件列表）；没有 `mkvmerge` 时退回 `ffprobe`（此时会提示「部分轨道细节可能缺失」）；
2. **补充信息**：有 `ffprobe` 时再补 HDR 类型（HDR10 / HLG / Dolby Vision）、编码 Profile、视频码率；没有码率时按「文件大小 ÷ 时长」估算并标注「（估算）」；
3. **章节**：有 `mkvextract` 且是 `.mkv` 时，用 `mkvextract chapters` 读出完整章节列表；
4. **附件**：字体文件名、MIME、大小；
5. **同级素材**：扫同目录，找出候选字幕 / 音频 / 字体（规则见 2.10），并对匹配到的字幕**自动探测编码**（UTF-8 / GB18030 / BIG5）。

轨道 ID 使用 mkvmerge 的 0 基编号，界面上统一显示成「#1、#2…」的 1 基序号，避免对不上。

### 2.4 视频页（只读）

视频轨**不可删除、不可编辑**，只展示：编码（H.264 / HEVC / AV1…）、分辨率、动态范围（SDR / HDR10 / HLG / Dolby Vision）、码率（估算会带 ≈ 与「（估算）」）、帧率、时长、轨道总数、容器格式。

### 2.5 音频页

表格 / 卡片两种形态（桌面表格、手机卡片），每条音频轨支持：

| 能力 | 说明 |
| --- | --- |
| 保留勾选 | 取消勾选 = 删除该轨（执行前会警告「该操作不可撤销」）；可再点「恢复」取消删除 |
| 排序 | ↑ / ↓ 按钮在同类型轨道内自由移动；顺序决定播放器里的轨道列表顺序 |
| 语言 | 下拉选 ISO 639-2 / BCP 47 代码（简体 `zh-Hans`、繁体 `zh-Hant`、`jpn`、`eng`、`yue`…），也支持「自定义…」手填；留空统一按 `und` |
| 轨道名 | 任意文本，例如「国配」「京译」「评论音轨」 |
| 默认 / 强制 | 两个开关，对应 Matroska 的 default / forced 标记 |
| 新增音轨 | 从目录选音频文件（`aac / flac / mka / ac3 / eac3 / dts / mp3 / m4a / opus / wav`）或上传小文件；新增轨同样可设语言 / 名称 / 默认 / 强制 |
| 延迟校正 `--sync` | 每条新增轨可填毫秒（正数=延后，负数=提前），最终写成 mkvmerge 的 `--sync` |
| 估偏移 | 「估偏移」按钮调用实验接口，自动把估计值写进 sync 输入框（见 2.16） |
| 时长比对 | 新增音频与视频时长差超过阈值时，预览里会给出黄色警告（多半不是同一版本） |

### 2.6 字幕页

与音频页操作一致，额外有：

- 「内嵌」标记：原文件里已有的字幕轨显示「SRT · 内嵌 / ASS · 内嵌」等，提示它不是外挂文件；
- **字幕编码**下拉（仅对新增字幕）：`自动` / `UTF-8` / `GBK` / `BIG5`。选「自动」时按探测结果处理，非 UTF-8 会在预览里提示「将转换为 UTF-8」；手选时直接给 mkvmerge 传 `--sub-charset`；
- 支持的外挂字幕格式：`.srt`、`.ass`、`.ssa`、`.vtt`；
- 新增字幕与视频时长不一致时，除了警告还会**强制**在预览弹窗里勾选「我已知晓时长不一致，仍要执行」才允许提交。

### 2.7 附件页（只允许字体）

Matroska 附件常被用来内嵌字体（特效字幕必需）。插件**只接受 `.ttf` / `.otf` / `.ttc`**，其它扩展名会被直接拦下。

- 已有附件：显示文件名、类型（TrueType / OpenType / TrueType Collection）、大小，可「标记删除」再「恢复」；
- 新增字体四条来源：
  1. **从目录选择字体**（推荐，字体通常超过上传上限）；
  2. **上传字体**（受上传上限约束）；
  3. **解压字体压缩包**：从目录选一个压缩包，或直接输入压缩包完整路径，解压其中的字体加入附件；
  4. **从目录批量解压**：给一个目录路径，扫描其下（可勾「包含子目录」）最多 50 个压缩包，逐个解压出字体；
- 还有「**扫描同目录字体**」：把视频同目录（含 `fonts/` 子目录）的字体一次性加入附件；
- 去重规则：**同路径或同名（忽略大小写）都视为重复**，重复的会跳过并提示跳过数量，不会把同名字体加两遍；
- 解压只保留字体，非字体文件在临时目录里直接丢弃。

### 2.8 章节与容器标题

- **处理方式**三选一：
  - 保留（`keep`，默认，不动章节）；
  - 清空（`clear`，预览会警告「章节将被清空」）；
  - 导入（`import`，从媒体根目录或插件上传目录选章节文件）。
- **章节文件格式**：OGM XML（`<?xml ...><Chapters>` 结构，mkvmerge / mkvpropedit 原生）与 ffmetadata（`;FFMETADATA1` 开头）；两种都接受，后端统一解析成「起点 / 终点 / 标题」列表，再按引擎需要分别序列化成 OGM 或 ffmetadata（ffmpeg 降级时用后者）。
- 章节文件扩展名限定 `.xml` / `.txt` / `.chap` / `.ffmeta`，且必须位于媒体根目录或插件上传目录内。
- **容器标题**：填了才改，留空 = 不修改。打开文件时标题框默认填当前容器标题（没有则用文件名去扩展名）。

### 2.9 高级：附加参数

给熟悉 mkvmerge 的用户留的口子：把自定义参数**追加到自动生成的 mkvmerge 命令行**。

- 一行一个参数（换行分隔，自动 trim、去空行）；
- 点「**验证并应用**」会立即跑一次 `/plan` 校验，把错误显示在输入框下方；没问题就提示「已应用：预览里的命令已包含这些参数」；
- **被禁止的参数**（出现即拒绝执行）：
  - `-o` / `--output` / `--output=...`——输出路径由插件控制；
  - 任何**已存在的绝对路径文件**（防止偷偷引入别的输入文件）；
  - 再次引用源文件本身。
- **只对 mkvmerge 生效**：如果当前计划走 mkvpropedit 或 ffmpeg，会给出阻塞项「附加参数只能用于 mkvmerge」；
- 只填附加参数（其它什么都没改）也会触发一次 mkvmerge 重封装，不会被判成「没有任何修改」。

常用示例：`--default-track-flag 2:1`、`--language 2:chi`、`--no-audio`。

### 2.10 同级素材自动发现 / 自动导入

打开文件时会扫同目录，规则写死在代码里，避免「把隔壁集的字幕挂到这一集」：

| 类型 | 收录条件 | 默认勾选 |
| --- | --- | --- |
| 字幕 | 文件名主干与视频**前缀匹配**（去掉空格 `.` `_` `-` 括号等分隔符后比较，相同或以任一方开头），或宽松匹配「字幕名以视频名开头」（如 `E01.cht.srt`） | **前缀匹配的默认勾选** |
| 音频 | 只收前缀匹配项 | 默认不勾 |
| 字体 | 同目录全部字体 + `fonts/` 子目录全部字体 | 默认不勾 |

- 面板按页签分类型显示（字幕页只看字幕、音频页只看音频、附件页只看字体），每条显示「语言 · 扩展名」小标签；
- **挂载 / 已挂载·点击收回**按钮：一键把当前页签的候选全部加入；收回时**只移除由自动导入或挂载按钮加进来的条目**，你手动加的不会被误删；
- 设置页三个开关（自动导入同名字幕 / 同名音频 / 同目录字体）控制「打开文件时是否自动挂载」；
- 勾选 = 作为新增轨道 / 附件写入，**不复制、不移动源文件**。

### 2.11 输出与备份

**两种输出模式**：

| 模式 | 行为 | 适用 |
| --- | --- | --- |
| 输出到目录（`dir`，默认） | 写到输出目录，文件名 = 原名（`.m2ts` 源自动改后缀 `.mkv`）；**目标已存在会被阻塞**（不会覆盖） | 想先对比成品、保留原片 |
| 原地替换（`replace`） | 用成品替换源文件；默认**先做临时备份**，成功后删除备份，失败时保留备份并尝试还原源文件 | 确定要就地更新 |

- 原地替换可以勾「**不保存临时备份**」：直接替换，失败时没有恢复副本（预览里会红字提示，历史里也会标注「未做临时备份（不可回滚）」）；
- **`.m2ts` / 非 MKV 源不能原地替换**（必须先重封装成 MKV），界面会自动禁用该选项并提示；
- 备份文件名形如 `原文件名.20261110-233000.mkv.bak`，按「失败备份保留份数」清理最旧的 `.bak`（0 = 不自动清理）；
- 落盘全程用「临时文件 + 原子替换」：命令写到 `work/<任务ID>/` 下的临时文件 → 校验通过 → `os.replace` 落盘；中途失败 / 取消会清理临时文件。

### 2.12 预览确认（动手前的最后一道闸）

点「预览并确认」（队列任务编辑时是「预览并更新」）会弹出预览窗，内容是：

1. **摘要**：执行引擎、保留轨道数、新增字幕 / 音轨 / 字体清单、删除的轨道与附件、逐项属性修改（`#2 chi → zh-Hans` 这种）、章节处理方式、容器标题；
2. **输出信息**：输出路径；原地替换时显示备份路径，或红字「不做临时备份，失败时无恢复副本」；还有磁盘空间提示；
3. **阻塞项（红色）**：存在任何一条就**不能**确认执行；
4. **警告（黄色）**：可以确认，但要看清楚；
5. **命令详情**（可折叠）：每条将执行的命令行，参数原样展示；
6. 时长不一致时的**强制勾选**框。

常见的阻塞项（`blockers`）与警告（`warnings`）：

| 类型 | 文案（节选） |
| --- | --- |
| 阻塞 | 没有任何修改，请先调整轨道、字幕、附件或章节 |
| 阻塞 | 未安装 MKVToolNix，请先在设置里安装或指定 mkvmerge 路径 |
| 阻塞 | 当前只有 ffmpeg，未开启「降级执行」；请安装 MKVToolNix 或到设置里开启降级 |
| 阻塞 | 至少需要保留一条视频轨 / 至少需要保留一条轨道 |
| 阻塞 | 输出文件已存在：… ／ 输出文件不能与源文件相同，请改用原地替换模式 |
| 阻塞 | 输出目录剩余空间不足：需要约 X，可用 Y |
| 阻塞 | 附加参数不允许包含 -o / --output（输出路径由插件控制） |
| 阻塞 | 新增素材暂不支持其它 MKV 容器，请提供音频或字幕文件 |
| 阻塞 | 附件只允许字体文件（ttf/otf/ttc） |
| 警告 | 将删除 N 条轨道，该操作不可撤销（请确认输出文件无误） |

| 警告 | 内封成功后将删除源外挂字幕文件（仅在「原地替换 + 删除」配置下） |

### 2.13 队列

- **两种入队语义**：
  - 「**预览并确认**」= 直接入队，worker 有空位就开始；
  - 「**仅加入队列**」= 入队但标记为「待启动（hold）」，不会被调度，直到你点行内「开始」或页头「全部开始」。
- **并发数** 1~3（默认 1）：机械盘建议 1，SSD 可 2~3；可在队列页直接切换，立即生效（调小时多余的 worker 会主动退出）。
- **暂停 / 继续队列**：暂停后当前任务跑完不再取新任务。
- **排序**：置顶 / 上移 / 下移（不做拖拽）；运行中的任务不能调序，只能取消。
- **编辑排队任务**：仅「待启动」任务，或「队列已暂停时的等待任务」可以编辑；点「编辑」把该任务的计划回填到编辑器，改完提交走 `/jobs/{id}/update`，**更新原任务而不是新建**。
- **取消**：等待中的任务立即取消并写历史；运行中的任务发终止信号，worker 在下一次输出行检查时抛取消异常。
- **清空等待**：一次清掉所有等待任务（各自写一条「已取消」历史）。
- **持久化与恢复**：等待队列写 `queue.json`，插件重载 / 容器重启后等待任务自动恢复；上次正在运行的任务会被标记为「中断」写入历史（错误信息「插件重启导致任务中断，临时文件已清理，请重新提交」）。
- **进度**：`mkvmerge` 读 `#GUI#progress` 百分比；`ffmpeg` 读 `time=` 与总时长换算；`mkvpropedit` 直接到 100%；「复制」步骤按字节数自算进度，多条命令按权重合并成总进度，队列页还会显示「约 X 剩余」。
- **退出码语义**：`mkvmerge` / `mkvpropedit` 的退出码 **1 = 完成但有警告**，按成功处理并把警告并入任务告警；其它工具只认 0。

### 2.14 历史

每条记录包含：时间、文件名与路径、输出位置、操作摘要（如 `+2 素材 · -1 轨道 · 改 3 项属性`）、结果（成功 / 失败 / 取消 / 中断）、耗时、告警小旗标、备份状态、命令与日志尾部（最多 200 行）。

- **筛选**：全部 / 成功 / 失败 / 取消；
- **回滚**：只对**失败且有备份**的记录出现（因为成功任务会删除临时备份）；回滚 = 把 `.bak` 复制成临时文件再原子替换回目标位置；
- **重新打开**：按记录里保存的编辑配置**回填编辑器**（轨道、附件、章节、输出设置），旧记录没有配置时只打开文件；
- **删除 / 清空历史**：只删记录，**不删备份文件**；同时会清理只被该记录引用的临时上传素材；
- 历史保留条数由设置控制（默认 200，范围 10~1000），超出后自动裁剪最旧的。

### 2.15 日志与诊断

- 插件把「启动 / 停止」「任务命令」「成功 / 失败」统一写成 **一个文件**：`<LOG_PATH>/plugins/mkvtoolkit.log`（即容器里的 `/config/logs/plugins/mkvtoolkit.log`）；后端提供 `/logs` 接口读取该文件（默认 200 行，最多 500 行）——**当前版本页面里没有独立的日志面板**，日常看日志请直接看这个文件；
- **安装过程的实时日志**显示在设置页的「安装 XX」弹窗里（来自 `/status` 的 `engine_install.log_tail`，最多 80 行）；
- 找不到宿主 `LOG_PATH` 时回退到插件数据目录下的 `logs/`；
- **一键诊断**（设置页）会报告：五个工具的版本与路径、当前执行模式、是否 root、插件数据目录是否可写、每个媒体根目录「是否存在 / 是否可写 / 剩余空间」、上传上限是否合理，最后给一句「全部通过」或「N 项需要注意」。

### 2.16 偏移估计（实验能力）

对「新增音轨 / 字幕」提供粗对齐建议，点「估偏移」后自动填入 sync 输入框：

- **音轨**：用 `ffmpeg silencedetect`（阈值 -30dB、最短静音 0.25s，默认只分析前 900 秒）分别提取视频首音轨与新增音轨的静音边界，在 ±8 秒范围按 50ms 步进搜索最佳平移；置信度 ≥45% 且优势 margin ≥10 才标为可用；
- **字幕**：解析 srt / ass / ssa / vtt 的 cue 时间，在 ±15 秒范围按 250ms 步进搜索「cue 起点落在语音区间内比例」最高的平移；原本就对得上的会直接告诉你「字幕时间轴已对齐，无需 --sync」，偏移小于 400ms 视为 0；
- 精度百毫秒级，**只适合「同一内容、不同延迟」**；不可靠时会明确提示「估计不可靠（可能不是同一版本），请确认后再用」，请自己试看后决定。

### 2.17 界面与手机端

- 顶部栏：图标 + 名称 + 版本（`v0.1.51` 与 `UI 0.1.51`）+ 引擎状态条 + 编辑 / 队列 / 历史三个页签 + 设置齿轮 + 退出；
- 布局按**容器实际宽度**分三档（窄 <720 / 中 720~1100 / 宽 ≥1100），所以即使在 PC 的插件弹窗里也能正确切换成紧凑布局；
- 手机端：文件树变抽屉、轨道表格变卡片、弹窗全屏、底部出现「队列任务条」（运行中的文件名 + 进度 + 待处理数量）；
- 队列页签有数量角标；
- 有未保存修改时关闭文件会弹确认（「丢弃并关闭」）；
- 同一文件已有等待 / 运行中的任务时，再次提交会弹三选一：**更新现有队列任务** / **再提交一个新任务** / **取消**；
- 插件停用时整页显示「插件已停用」与启用步骤，并提供「前往设置启用」「刷新页面」两个按钮（遮罩延迟 400ms 显示，避免打开瞬间闪一下）。

## 三、安装与启用

只在 **MoviePilot V3** 上可用（`plugins.v3/mkvtoolkit`）；V2 仓库里没有这个插件。

1. **添加仓库**：MoviePilot → 设置 → 插件市场 → 添加插件仓库，填入
   `https://github.com/LXT-A-X/MoviePilot-Plugins`
   （或从「插件市场 → 第三方仓库」添加同一地址）。
2. **搜索安装**：市场里搜索「**MKV 工具箱**」或「MkvToolkit」→ 安装。V3 版当前为 **0.1.51**，要求 MoviePilot **≥ 3.2.0**。
3. **确认引擎**：装好后先打开插件页或插件设置页，看顶部三个状态条：
   - `mkvmerge 未安装` → 设置页点「安装 / 更新 → 一键安装全部（apt）」；容器不是 root 时改用「AppImage 解包」或「手动指定路径」；
   - `ffmpeg 未检测到` → 官方镜像自带，通常不会遇到；缺失时同样可在设置里单独点「安装 ffmpeg」；
   - 压缩包工具只要不打算解压 `7z / rar` 字体包，可以不管（`zip / tar` 用 Python 内置能力，不依赖外部程序）。
4. **配置**（设置页，详见[第五章](#五配置项详解)）：
   - 「媒体根目录」至少加一个（容器内绝对路径，如 `/media`、`/downloads`），否则文件树是空的；
   - 「输出目录」默认在插件数据目录下的 `output/`，可改成你媒体盘里的目录；
   - 其余项按需调整，默认值即可用。
5. **保存配置**：设置页底部「保存配置」。保存会**热应用**：正在等待 / 运行的任务不中断，新的根目录、并发数、历史条数立即生效。
6. **启用插件**：设置页最上方「启用插件」开关必须打开（新建插件默认开启）。如果之前停用过，打开开关并保存后刷新页面。
7. **验证**：回到「编辑」页 → 文件树应能看到根目录 → 点一个 `.mkv` → 能看到轨道 / 章节 / 附件统计，即安装成功。

> 插件页面可以通过 **侧栏「系统」分组 → MKV 工具箱** 全页打开，也可以从插件管理里点插件卡片打开（弹窗形态）。两种形态用的是同一个前端页面。

| 前置条件 | 是否必须 | 说明 / 缺失时的表现 |

| 不需要开放端口 | — | 插件通过宿主 API 通信，不监听任何端口 |

## 五、配置项详解

> 全部默认值来自后端 `DEFAULT_CONFIG`（`store.py`）与前端 `Config.vue` 的 `DEFAULTS`，并附后端 `normalize_config` 的取值校验。设置页分组与下表分组一致。

### 5.1 总开关与引擎

| 设置项（配置键） | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件（`enabled`） | `开` | 关闭后：停止任务队列、释放运行期资源，接口返回「插件未启用」，页面显示停用提示。**侧栏入口保留**，重新启用需回到插件设置页打开开关并保存 |
| 引擎模式（`engine_mode`） | `auto` | 下拉三项：自动（优先 mkvmerge）/ 仅 mkvmerge / 仅 ffmpeg（降级）。**当前版本执行时按工具探测结果自动选择引擎**，此项随配置保存（保留项，不改变实际选路） |
| mkvmerge 路径（`mkvmerge_path`） | 空 | 手填绝对路径，留空 = 自动探测。填了优先使用 |
| mkvpropedit 路径（`mkvpropedit_path`） | 空 | 同上 |
| mkvextract 路径（`mkvextract_path`） | 空 | 同上 |
| ffmpeg 路径（`ffmpeg_path`） | 空 | 同上 |
| 降级执行（`allow_ffmpeg_fallback`） | `关` | 缺 mkvmerge 时是否允许用 ffmpeg 真执行。默认关闭（只能预览）；开启后附件 / tags / 轨道 UID 等细节可能丢失 |

> `ffprobe` 没有独立的路径配置项，通过「插件数据目录 `bin/` → PATH → `/usr/bin`」探测，手填路径只对上面四个工具生效。

### 5.2 目录

| 设置项（配置键） | 默认值 | 说明 |
| --- | --- | --- |
| 媒体根目录（`roots`） | 空列表 | 可加多个，**必须是容器内绝对路径**（前端校验必须以 `/` 开头，如 `/media`、`/downloads`）；同一个路径不会重复添加；不存在或不是目录的项在后端会被丢弃。所有文件浏览与素材引用都被限制在这些根目录（及插件上传目录）内 |
| （目录树提示） | — | 只显示 `.mkv`/`.m2ts`、懒加载、顶部可搜索、路径必须落在根目录内 |

### 5.3 输出与备份

| 设置项（配置键） | 默认值 | 说明 |
| --- | --- | --- |
| 默认输出模式（`output_mode`） | `dir`（输出到目录） | 可选「原地替换」。打开文件时按此初始化输出选择；`.m2ts` 等非 MKV 源会强制为「输出到目录」 |
| 输出目录（`output_dir`） | 空 → 插件数据目录 `output/` | 容器内路径；保存时可填媒体盘路径。输出文件名 = 源文件名（保留扩展名，非 MKV 源改为 `.mkv`） |
| 备份目录（`backup_dir`） | 空 → 插件数据目录 `backup/` | 原地替换的临时备份位置；建议指向大容量盘 |
| 失败备份保留份数（`backup_keep`） | `3` | 范围 0~20，设置页可选 1 / 3 / 5 / 10；0 = 不自动清理。只清理失败任务遗留的 `.bak`（成功任务的临时备份会被删掉） |
| 输出后缀（`output_suffix`） | 空 | 追加在输出文件名主干后、扩展名前（如 `-edit` → `影片-edit.mkv`）。**设置页未暴露**，只能通过接口 / 配置文件写入 |

### 5.4 字幕与语言

| 设置项（配置键） | 默认值 | 说明 |
| --- | --- | --- |
| 内封后外挂字幕（`subtitle_after`） | `keep`（保留） | `keep` 保留 / `archive` 移到外挂字幕同目录的 `subs_done/` 子目录（重名加时间戳）/ `delete` 删除。**仅「原地替换」模式生效**：输出到新目录时源视频没改动，不会动外挂字幕 |
| 编码兜底（`subtitle_encoding`） | `auto` | 下拉：自动探测 / UTF-8 / GBK / BIG5。**当前版本新增字幕的编码实际由每条素材的「字幕编码」下拉与自动探测决定**，该全局项随配置保存（保留项） |
| 语言映射（`language_map`） | 26 条内置 | 「文件名片段 → ISO 639-2 语言码」，用于从文件名推断新增轨语言。内置：`zh/chs/cht/sc/tc/简/繁/中文/国语/国配/普通话/mandarin → chi`，`jpn/jp/日语/japanese → jpn`，`eng/en/英语/english → eng`，`yue/粤/粤语/cantonese → yue`，`kor/ko/韩语/korean → kor`。编辑方式：每行 `片段=语言码`，如 `.zh=chi`；最长片段优先匹配；识别不到为 `und` |

### 5.5 自动导入（打开文件时）

| 设置项（配置键） | 默认值 | 说明 |
| --- | --- | --- |
| 自动导入同名字幕（`auto_subtitle`） | `关` | 打开文件时，把**前缀匹配**的同名字幕自动加入字幕轨 |
| 自动导入同名音频（`auto_audio`） | `关` | 同上，音频 |
| 自动导入同目录字体（`auto_fonts`） | `关` | 打开文件时，把同目录（含 `fonts/`）的字体全部加入附件 |

### 5.6 执行与校验

| 设置项（配置键） | 默认值 | 说明 |
| --- | --- | --- |
| 并发数（`concurrency`） | `1` | 范围 1~3。机械盘建议 1，SSD 可 2~3；队列页也能实时改 |
| 时长误差阈值（`validation_tolerance`） | `2.0` 秒 | 范围 0.5~60。输出时长与源时长偏差超过阈值：默认只记告警；开启严格校验时判失败。同时也用于「新增素材与视频时长差」的预警判断 |
| 严格时长校验（`strict_duration_check`） | `关` | 开启后，时长偏差超过阈值直接判任务失败（默认关闭，避免误伤不同版本的音轨） |
| 历史保留（`history_keep`） | `200` 条 | 范围 10~1000，超出裁剪最旧记录 |
| 上传上限（`upload_max_mb`） | `50` MB | 范围 1~10240。**前后端双重校验**：前端用 `file.size` 先拦，后端边读边累计字节再拦。注意宿主 nginx 默认也是 50MB，实际能传多大以 nginx 配置为准 |

### 5.7 没有配置项的行为（写死在代码里）

| 行为 | 数值 |
| --- | --- |
| 字体压缩包上传上限 | 512 MB（目录解压单个包内字体 ≤500 个、累计 ≤512MB） |
| 一次批量解压的压缩包数量 | 最多 50 个 |
| 上传文件名安全处理 | 去掉 `\ / : * ? " < >` 与首尾空白，加 8 位随机前缀防冲突 |
| 任务日志尾部保留 | 历史记录里最多 200 行，任务详情接口默认 100 行 |
| 插件日志读取 | 默认 200 行，最多 500 行 |
| 路径解析 | 不在媒体根目录 / 上传目录内 → 直接拒绝；相对路径会被当成「根目录下的相对路径」处理 |
| 前端任务状态轮询 | 有 pending / running 时每 5 秒刷新一次 |

## 六、使用流程与典型场景

### 场景 A：首次配置（5 分钟）

1. 安装并打开插件 → 顶部若显示「未检测到 MKVToolNix」横幅，点「立即安装」（apt）或去设置页选 AppImage / 手动路径；
2. 进设置页 → 「目录 → 媒体根目录 → 添加」，填容器内路径（如 `/media`）→ 添加；
3. 检查「输出与备份」：默认输出到插件数据目录，如果你想直接产出到媒体盘，把「输出目录」改成例如 `/media/tmp_mkv`；
4. 点「一键诊断」，确认几个工具都是绿色、根目录「存在 · 可写 · 剩余空间」正常；
5. 「保存配置」→ 回编辑页，文件树出现内容即完成。

### 场景 B：给一集动画加国配音轨 + 特效字幕 + 字体（最常见的完整流程）

1. **选文件**：编辑页左侧文件树点进剧集目录，点 `.mkv`；
2. **看底子**：信息条会显示容器、体积、时长、轨道数、章节数、附件数；先确认视频轨、现有音轨是否合理；
3. **加音轨**：「音频」页 → 「从目录选择」→ 选国语 `.mka` → 出现在列表，标着「新增」→ 语言选「简体中文 (zh-Hans)」、轨道名填「国配」，按需打开「默认」；
4. **对时长**：如果预览提示「与视频时长相差 ±x.xs」，点该行的「估偏移」拿个建议 `--sync` 值（不可靠时自己试看），或换一个同版本文件；
5. **加字幕**：「字幕」页 → 「从目录选择」→ 选 `.ass`；编码选「自动」（非 UTF-8 会在预览里提示转换）；同理设语言 / 名称 / 强制标记；也可以直接在「同级自动发现」面板里勾选；
6. **加字体**：「附件」页 → 如果字体在视频同目录，点「扫描同目录字体」；如果是一个字体压缩包，点「解压字体压缩包」选包；也可以「从目录批量解压」；
7. **调顺序**：用 ↑ / ↓ 把「国语」排到第一条音轨，把「简体中文」排到第一条字幕（顺序影响播放器默认选择）；
8. **设输出**：选「输出到目录」（安全）或「原地替换」（默认会临时备份）；
9. **预览**：点「预览并确认」→ 逐条核对摘要、输出路径、警告与命令；
10. **执行**：点「确认执行」→ 任务入队；到「队列」页看进度；完成后在「历史」页看结果与耗时；
11. **抽查**：用播放器打开成品，确认音轨能切、字幕显示正常、字体生效；确认无误后再决定是否删除原片（插件不会自动删）。

### 场景 C：只改语言 / 默认轨 / 轨道名（最快路径）

这类操作不会重新封装：改完 → 预览（引擎会显示 `mkvpropedit`）→ 确认 → 执行。因为要先复制一份文件再改属性，耗时就等于「复制一遍文件」的时间，属于磁盘 IO 速度。

### 场景 D：批量处理一季（用「仅加入队列」）

1. 对第 1 集配置好编辑方案 → 点「**仅加入队列**」（任务进入「待启动」状态，不执行）；
2. 依次处理第 2、3… 集（每集都可复用同样的思路：同级素材面板 + 自动导入开关能省不少点击）；
3. 全部配好后到「队列」页 → 点「**全部开始**」（或按行点「开始」）；
4. 并发数设 1 时任务串行执行，适合机械盘；SSD 可调到 2~3。

> 小技巧：先把设置页的「自动导入同名字幕 / 同名音频 / 同目录字体」打开，打开每集时素材就自动挂好了，只需要确认。

### 场景 E：清章节 / 改标题 / 导入章节

「章节」页 → 处理方式选「清空」或「导入 XML」并选文件（`.xml` OGM 或 `.txt` ffmetadata）→ 「容器标题」填新标题（留空不改）→ 预览（会显示「章节：清空 / 导入」「容器标题：…」）→ 确认。

### 场景 F：把字体压缩包里的字体全部挂上

「附件」页有三个入口：

- **解压字体压缩包**：选单个包（可在文件选择器里直接粘贴压缩包完整路径）→ 自动解压出字体加入附件；
- **从目录批量解压**：填目录路径，勾「包含子目录」→ 扫描最多 50 个压缩包 → 逐个解压；
- **上传压缩包**：`.zip/.7z/.rar/.tar` 均可，最大 512MB（受 nginx 限制时请用前两种）。

解压出来的字体若与已有附件同名或同路径会**自动跳过**，并提示跳过数量。

### 场景 G：执行失败后回滚（仅原地替换）

1. 「历史」页找到那条失败记录（备份状态显示「备份可回滚」）；
2. 点「回滚」→ 插件把 `.bak` 复制回目标位置（原子替换），提示「已从备份回滚」；
3. 如果备份状态是「备份已删除（不可回滚）」或「未做临时备份（不可回滚）」，说明没有可用的恢复副本；
4. 想再试一次：点「重新打开」，编辑器会按记录里的配置回填，改完重新预览提交。

### 场景 H：手机上操作

打开插件（宿主弹窗或侧栏全页）→ 「文件」按钮打开抽屉选剧集 → 轨道变为卡片列表，勾选 / 语言 / 名称 / 延迟都能改 → 底部「预览并确认」→ 确认执行。队列与历史页同样适配窄屏。

### 场景 I：修改一个已排队但还没开始的任务

1. 「队列」页找到「待启动」任务（或队列已暂停时的等待任务）→ 点「编辑」；
2. 编辑器载入该任务的计划，按钮变成「更新任务 / 预览并更新」；
3. 改完预览确认 → 走更新接口覆盖原任务计划（**不会新建任务**），队列里的位置与 hold 状态保持；
4. 想放弃修改：点提示条里的「取消队列任务编辑」。

## 七、与其他组件的联动

### 7.1 与 MoviePilot 宿主

| 项 | 说明 |
| --- | --- |
| 侧栏入口 | 注册到「系统」分组的全页入口（图标 `mdi-video-box`，权限 admin，排序 120） |
| 插件卡片 | 插件管理里点卡片也能打开同一页面（弹窗形态）；卡片图标使用仓库内的公网图片地址，页面内左上角图标内联在前端 bundle 里（不依赖宿主静态路径） |
| 数据目录 | 通过宿主 `get_data_path()` 拿到插件数据目录，**不写插件源码目录** |
| 日志目录 | 按宿主 `LOG_PATH` 约定写到 `<LOG_PATH>/plugins/mkvtoolkit.log`，与其它插件保持一致 |
| 配置存储 | 使用宿主插件配置（前缀 `mkvtoolkit_`），保存后热应用 |

### 7.2 与 Emby / Jellyfin

**没有 API 层面的对接**（不调用 Emby/Jellyfin 接口、不发通知、不订阅它们的 Webhook）。联动方式是「文件级」的：

- 插件改的正是媒体库里那些 `.mkv` 文件本身，所以内封后的字幕 / 音轨 / 字体对 Emby、Jellyfin、Plex、电视盒子、播放器都生效；
- 用了「原地替换」后，建议在 Emby/Jellyfin 里对该条目「刷新元数据 / 重新扫描」，让媒体信息里的轨道列表及时更新；
- 用了「输出到目录」时，成品还在你的输出目录里，需要自己移动到媒体库目录并触发扫描。

### 7.3 与下载器

**无联动**：插件不监听下载器、不扫下载目录、不订阅 MoviePilot 的整理入库事件。

实际用法是把「下载完成的目录」也加成一个媒体根目录（例如 `/downloads`），然后在文件树里手动挑文件处理。整理入库后的文件同理（把媒体库根目录加成根目录）。

### 7.4 与通知 / Telegram

**无**：插件不发送任何通知（没有 `post_message` 调用），也没有 Telegram 命令。所有结果都在「历史」页与日志文件里看。

### 7.5 与 OpenWrt / 代理 / 其它插件

**无耦合**。本插件唯一的外网行为是「AppImage 安装」时从官方地址下载 MKVToolNix AppImage（`mkvtoolnix.download`）；apt 安装走容器自身的软件源。若容器网络受限，请改用「手动指定路径」把二进制放进插件数据目录 `bin/`。

## 八、安全与权限

### 8.1 谁能用

- 插件 `auth_level = 2`（管理员级），页面入口在侧栏「系统」分组且 `permission: admin`；
- 后端所有接口声明 `auth: "bear"`，即必须带登录令牌；未登录 / 普通用户无法直接调用；
- 因此**只有 MoviePilot 管理员**能浏览媒体目录、提交任务、安装引擎。别把管理员账号共享给不该操作媒体文件的人。

### 8.2 文件访问边界

- 所有路径都先 `resolve`（展开符号链接、去掉 `..`）再校验：
  - 视频 / 目录：必须在**配置的媒体根目录**内，否则报「路径不在已配置的媒体根目录内」；
  - 素材（字幕 / 音频 / 章节 / 字体 / 压缩包）：必须在媒体根目录**或插件上传目录**内；
  - 输出目录 / 备份目录：由插件创建与写入（`ensure_dir`），属于插件自管范围。
- 上传文件名做严格清洗（去掉 `\ / : * ? " < >` 等），并加随机前缀，防止覆盖与路径注入；
- 压缩包解压做了**路径穿越防护**（拒绝绝对路径、`..` 段、逃出目标目录的成员）＋ **数量与体积上限**（≤500 个字体、≤512MB），避免压缩炸弹；
- 附件只允许 `.ttf / .otf / .ttc`；新增素材不支持「再塞一个 MKV 进去」。

### 8.3 危险操作清单（请务必先看预览）

| 操作 | 风险 | 建议 |
| --- | --- | --- |
| 原地替换 + 不保存临时备份 | 替换失败或被误操作时**没有任何恢复副本** | 首次处理先选「输出到目录」验证成品，再考虑原地替换 |
| 删除轨道 | 成品里就真的没了（源文件若被替换也不可恢复） | 预览里逐条核对「✕ 删除音轨 …」 |
| 清空章节 | 章节信息丢失 | 需要时先「导入」备份的章节 XML |
| 内封后删除外挂字幕 | 源 `.ass/.srt` 被删除（仅原地替换模式） | 先把 `subtitle_after` 设为「保留」或「移到归档目录」 |
| 附件删除 | 特效字幕字体丢失 → 播放时变方块 | 确认成品播放正常后再清理原字体 |
| 附加参数 | 参数错误可能导致输出异常（虽然插件会拦 `-o` 与输入文件） | 用「验证并应用」先看命令，再小范围试一个文件 |
| apt 安装引擎 | 需要 root，会改动容器系统包 | 更稳妥的是 AppImage（免 root，只写插件数据目录） |

### 8.4 数据与隐私

- 插件自身**不收集、不上报**任何数据；
- 历史记录会保存：源文件完整路径、输出路径、执行的命令行、日志尾部（最多 200 行）。这些内容留在插件数据目录的 `history.json` 里，**删除 / 清空历史即可清除记录**（不会删除备份文件）；
- 上传的素材存放在插件数据目录的 `uploads/`，任务结束（成功 / 失败 / 取消）或清空等待 / 删除历史时会清理，仍被其它任务引用的不会误删；
- 配置文件里**没有密码、令牌、Cookie 一类敏感字段**（本插件不需要任何第三方账号）；
- 插件日志同样包含文件路径与命令行，位于 `/config/logs/plugins/mkvtoolkit.log`，按需清理。

### 8.5 稳定性保护

- 同一个文件已有等待 / 运行中的任务时，提交前会先查 `/file-statuses` 并弹三选一，避免重复排队把同一文件写两遍；
- 执行前再次确认「源文件大小」与入队时一致，不一致直接失败并提示「源文件在入队后发生变化，请重新预览再提交」；
- 输出**先写临时文件、校验轨道数与时长后再原子替换**，中途失败不会留下半个文件；
- 插件停止 / 重启：运行中的任务被终止并持久化等待队列，下次启动把中断的任务写进历史。

## 九、常见问题 FAQ

### Q1. 页面一直提示「未检测到 MKVToolNix，当前只能预览不能执行」，按钮显示「需安装 MKVToolNix」

按顺序排查：

1. 设置页「引擎」区看 5 个工具的状态条：`mkvmerge` 显示「未检测到」就是根因；
2. 点「重新检测」（有些容器装完包需要刷新 PATH / 重启容器才可见）；
3. 点该工具行右侧的「安装 mkvmerge」（apt），或「安装 / 更新 → AppImage 解包」，或手填 `mkvmerge` 绝对路径；
4. 若安装日志出现「当前容器不是 root，无法使用 apt 安装」→ 换成 AppImage 或手动路径；
5. 实在装不上：设置页打开「降级执行」（需要 ffmpeg 可用）可以先用 ffmpeg 跑，但附件 / tags 等会减配——**不推荐**长期这样用。

### Q2. 文件树一直是空的 / 提示「还没有配置媒体根目录」

- 设置页「目录 → 媒体根目录」里至少要有**一条容器内绝对路径**；
- 路径必须真实存在于容器内（和你 `docker-compose` 里映射的路径一致），不是宿主机路径；
- 加完记得点「保存配置」；
- 如果根目录下没有子目录、也没有 `.mkv`，会提示「当前根目录下没有子目录或 .mkv 文件」。

### Q3. 上传字幕 / 音频失败，提示超过上传上限

- 默认上限 50MB（可调），但**宿主 nginx 默认请求体上限也是 50MB**，调大插件配置不一定能突破；
- 音频、字体这类大文件请改用「**从目录选择**」（文件放在媒体根目录内即可，插件只引用不复制）；
- 字体压缩包可以走「上传压缩包」（上限 512MB），超过限制就用「从目录批量解压」；
- 后端对扩展名也做白名单校验，扩展名不对会提示「不支持的文件类型」。

### Q4. 点「预览并确认」后提示「输出文件已存在」或「输出文件不能与源文件相同」

- 「输出到目录」模式下，目标文件已存在会被当成阻塞（插件**不会覆盖**）：换输出目录、改名（用「输出后缀」）、或先移走旧成品；
- 「输出文件不能与源文件相同」通常是把输出目录设成了源文件所在目录：改用「原地替换」或换输出目录。

### Q5. 提示「输出目录剩余空间不足：需要约 X，可用 Y」

插件按「源文件大小 + 新增素材大小」×1.02 预估所需空间。处理办法：清空间、把输出目录/备份目录换到大容量盘、或改成「原地替换」（但请先确认风险）。

### Q6. 提交时提示「没有任何修改」，但我明明改过

只有这几类算「有修改」：删轨道、加素材、重排轨道、改属性（语言 / 名称 / 默认 / 强制）、增删附件、章节（清空 / 导入）、容器标题、附加参数、非 MKV 源重封装。如果你只是点开了文件、什么都没改，就会得到这个提示。注意：**把某项改回原值等于没改**（例如语言从 `und` 改成 `und`）。

### Q7. 预览提示「时长不一致」不让执行 / 历史里看到时长告警

- 新增音轨或字幕与视频时长差超过「时长误差阈值」（默认 2 秒）会给出警告，通常是「不是同一版本」；
- 预览弹窗里必须勾选「我已知晓时长不一致，仍要执行」才能提交；
- 想让它直接判失败：设置页打开「严格时长校验」；
- 更推荐的做法：点「估偏移」拿到 `--sync` 建议值，或换一个同版本素材。

### Q8. 任务失败，错误是「校验失败：audio 轨道数量应为 3，实际 2」

执行完成后插件会重新探测输出文件，**轨道数量必须与计划完全一致**（视频 / 音频 / 字幕分别核对），不一致就判失败。常见原因：

- 源文件在入队后被改动（同一条错误链里也可能提示「源文件在入队后发生变化」）；
- 素材文件本身包含多个轨道 / 被其它程序占用；
- 磁盘写入异常。处理：看「历史 → 该记录 → 命令与日志尾部」，确认命令与源文件状态后重新预览提交。

### Q9. 队列里任务的「编辑」按钮是灰的 / 点不了

只有「待启动（hold）」任务，或「队列已暂停时的等待任务」可以编辑（后端也限制只能改 `pending` 状态）。运行中的任务只能取消。想改一个已经在跑的任务：等它结束，或在队列里取消后重新配置。

### Q10. 「历史」里的记录没有「回滚」按钮

按设计，**只有失败且保留备份的记录**才能回滚：

- 成功任务：临时备份成功后立即删除 → 显示「备份已删除（不可回滚）」；
- 勾了「不保存临时备份」→ 显示「未做临时备份（不可回滚）」；
- 输出到目录模式没有备份概念 → 无回滚按钮。

### Q11. 插件页面显示「插件已停用」

按页面提示操作：

1. 点「前往设置启用」→ 打开「启用插件」开关 → 保存配置；
2. 或到插件管理页把插件启用 / 启动并「应用保存」；
3. 还不行就点「刷新页面」（或强制刷新浏览器）。

如果页面在打开瞬间闪一下停用提示又恢复，是宿主状态回填时序问题，已在 0.1.47 之后加了 400ms 延迟显示。需要排查时，可在浏览器控制台查看 `window.__mkvToolkitStatus`（记录每次 `/status` 的 enabled 与版本）。

### Q12. 压缩包解压报「需要系统安装 7z 或 unrar」/ `rar` 解不了

- `zip`、`tar`（含 `.tar.gz/.tar.bz2/.tar.xz`）由 Python 内置库解压，不需要外部程序；
- `7z` / `rar` 需要容器内有 `7z`（或 `7zz`/`7za`）或 `unrar`；在设置页「压缩包解压」一行点「安装 7z」「安装 unrar」即可（仅 apt，需要 root）；
- 有 `7z` 就能解 `rar`，`unrar` 是可选的备选；两样都没有时，顶部压缩包状态条会显示「压缩包 zip/tar」并可点击跳到设置页安装。

### Q13. 修改后的文件在 Emby / Jellyfin 里看不到新轨道

媒体服务器有缓存：在 Emby / Jellyfin 里对该条目执行「刷新元数据 / 重新扫描媒体库」，再重新打开播放页；播放器端（尤其电视 App）可能需要完全退出重进才会重新拉取轨道列表。

### Q14. 插件重启后，之前在跑的任务不见了

运行中的任务无法跨进程恢复：插件会把它们写成一条「中断」历史（错误信息「插件重启导致任务中断，临时文件已清理，请重新提交」），**等待中的任务会自动恢复**（状态「等待中（已恢复）」或「待启动（已恢复）」）。重新预览提交被中断的那几个即可。

### Q15. 日志在哪看？

三个地方：

1. **插件日志文件**：`/config/logs/plugins/mkvtoolkit.log`（启动 / 停止、任务命令、成功 / 失败都在这里；页面当前没有单独的日志面板，需要直接看文件或用 `/logs` 接口取最近 200 行，最多 500 行）；
2. **安装日志**：设置页点开安装弹窗，里面实时滚动（来自 `/status` 的 `engine_install.log_tail`，最多 80 行）；
3. **任务级日志**：「历史 → 记录」里的命令与日志尾部（最多 200 行），失败原因写在 `error` 字段里。
